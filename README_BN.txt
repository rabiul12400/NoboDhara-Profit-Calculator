NoboDhara Profit Calculator – Android APK Project

এই ZIP ফাইলে Android Studio project source আছে। এটি সরাসরি APK নয়।

APK বানানোর সহজ উপায়:
1. ZIP ফাইলটি Extract করুন।
2. GitHub-এ নতুন একটি repository তৈরি করুন।
3. ZIP-এর ভেতরের সব ফাইল repository-তে upload করুন।
4. GitHub repository-তে Actions tab খুলুন।
5. "Build Android APK" workflow নির্বাচন করে Run workflow চাপুন।
6. Build শেষ হলে Artifacts থেকে NoboDhara-Profit-Calculator-APK ডাউনলোড করুন।
7. ZIP extract করলে app-debug.apk পাবেন। Android ফোনে সেটি install করুন।

বিকল্প: Android Studio-তে এই project খুলে Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।

নোট: প্রথমবার install করার সময় Android-এ browser/file manager থেকে app install permission দিতে হতে পারে।
